# Reflection

File này được cập nhật tự động từ kết quả thực nghiệm khi chạy toàn bộ `classification.ipynb`.

Phần tổng kết so sánh TF-IDF + Logistic Regression, Average Word2Vec + Logistic Regression, TF-IDF + Linear SVM và TF-IDF unigram + bigram. Kết luận dựa trên accuracy, precision, recall, F1, training time, confusion matrix và các lỗi được lấy từ test set.

## Files
* `calculations.md` — calculation exercises.
* `prediction.md` — predictions before experiments.
* `implementation.py` — minimal TF-IDF implementation and unit tests.
* `experiments.ipynb` — notebook with TF-IDF experiments, preprocessing comparison, document search, evaluation, and error analysis.
* `results.csv` — retrieval results for the four queries.
* `reflection.md` — reflection and analysis of the experiments.
## Implementation
The TF-IDF implementation is maintained separately from the experiment notebook. The notebook is used for running experiments and analyzing the resulting representations and search results.
## Run
Open experiments.ipynb in Google Colab, upload the original .json.gz corpus when prompted, then run the cells from top to bottom.
